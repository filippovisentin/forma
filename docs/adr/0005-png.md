# ADR 0005 — PNG encoding (`png` crate)

- Status: accepted
- Date: 2026-10-10

## Context
`forma-cli render` already writes PNG images, and the desktop app needs the same
for View → Capture View to Image (Rhino's ViewCaptureToFile): a picture of a
viewport with its texts, dimensions and points, to put on a board or in a report.

## Options
1. Write BMP by hand: no dependency, but large files that many tools handle badly.
2. `image`: decodes and encodes everything, but pulls in many codecs we do not need.
3. `png` (image-rs): the small, widely used PNG encoder `image` itself is built on.

## Decision
`png` 0.18, in `forma-cli` and `forma-ui`, only to encode RGBA8 images.

## Consequences
One small pure-Rust dependency (plus `crc32fast`, `flate2` already in the tree).
Other image formats are not supported; PNG is enough for boards and reports.
