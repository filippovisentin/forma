# ADR 0002 — `.3dm` I/O through openNURBS

- Status: accepted (Linux verified; Windows via CI, see below)
- Date: 2026-10-09

## Context
Forma must open and save Filippo's Rhino 8 files (`.3dm`, archive version 80, cm units,
nested layers, extrusions, breps, meshes, blocks). No mature Rust crate reads `.3dm`.
McNeel publishes openNURBS, the C++ reference implementation, under a permissive licence.

## Options
1. Write our own `.3dm` reader in Rust — huge, undocumented chunk formats, compression.
2. Call `rhino3dm` (Python/JS wrapper of openNURBS) out of process — extra runtime, slow.
3. **Link openNURBS directly** behind a tiny C ABI shim.

## Decision
Option 3.
- openNURBS is a git submodule at `third_party/opennurbs` (shallow), never copied.
- `forma-io-3dm/build.rs` builds the `opennurbsStatic` CMake target in Release with the
  `cmake` crate, and compiles `shim/shim.cpp` with the `cc` crate. Only plain C types cross
  the boundary (`extern "C"`), so no `cxx`/`bindgen` dependency is needed.
- Gotcha: openNURBS' bundled zlib calls back into `zcalloc`/`zcfree`, defined in
  `opennurbs_zlib_memory.cpp`, an object nothing else references. The build script compiles
  it into a separate static lib linked *after* zlib to close the cycle.

New build dependencies: `cmake` 0.1, `cc` 1 (build-time only).

## Verification
- `cargo test -p forma-io-3dm`: write → read round trip (units, tolerance, layer, geometry),
  UTF-8 layer names, missing files.
- `tests/real_files.rs`: counts on `binario.3dm` and `gggg.3dm` match rhino3dm exactly
  (object types, nested layer paths, materials, blocks, solids, extents). Reading the 90 MB
  `gggg.3dm` takes ~1 s.

## Consequences
- First clean build is ~2 minutes (openNURBS is ~250 C/C++ files); cached afterwards.
- A C++ toolchain is required: MSVC Build Tools on Windows, g++/clang + CMake on Linux.
- Contributors must run `git submodule update --init --depth 1` after cloning.
- Windows linking (rpcrt4, shlwapi, `/bigobj`) is configured but not yet verified on a
  real Windows build; the GitHub Actions Windows job is the check.
