FORMA 0.3 — modellatore personale in stile Rhino
=================================================

Avvio
  Doppio clic su forma.exe. Se Windows mostra "PC protetto da Windows":
  "Ulteriori informazioni" -> "Esegui comunque" (l'app non è firmata).

Interfaccia
  4 viste (Top, Perspective, Front, Right). Doppio clic sul titolo di una vista
  per ingrandirla / tornare a 4. In alto i menu (con sottomenu come Rhino) e le
  schede Standard / Curve Tools / Solid Tools / Transform / Set View; a sinistra
  la barra strumenti; a destra i pannelli Properties (F3) e Layers; in basso la
  riga di comando e la barra di stato.

Gumball (oggetti selezionati)
  Frecce rossa/verde/blu ..... trascina per spostare lungo X / Y / Z
  Quadratini ................. trascina per spostare nel piano
  Archi ...................... trascina per ruotare (a scatti di 5° con Grid Snap)
  Clic su una maniglia ....... scrivi la distanza (o l'angolo) e Invio
  Si attiva/disattiva dal pulsante "Gumball" (scheda Standard) o dal menu View.

Mouse (come Rhino)
  Sinistro ................... seleziona / clicca punti
  Trascina a destra (→) ...... selezione a finestra (oggetti interi)
  Trascina a sinistra (←) .... selezione crossing (oggetti toccati)
  Shift+clic / Ctrl+clic ..... aggiungi / togli dalla selezione
  Destro trascinato .......... ruota (Perspective) / sposta (Top, Front, Right)
  Shift+destro, rotella premuta  sposta la vista
  Rotella .................... zoom verso il cursore
  Clic destro ................ Invio (conferma o ripete l'ultimo comando)

Tastiera
  Scrivi direttamente: il testo va nella riga di comando.
  Invio / Spazio = conferma o ripete · Esc = annulla · Canc = elimina
  F8 = Ortho (o tieni premuto Shift) · F9 = Grid Snap · F7 = griglia
  Ctrl+Z / Ctrl+Y / Ctrl+A / Ctrl+S / Ctrl+O / Ctrl+N

Coordinate (nel piano della vista attiva)
  100,50        assoluto            @100,50   relativo all'ultimo punto
  @300<45       distanza<angolo     300       lunghezza verso il cursore

Comandi
  Curve:     Line, Polyline (C chiude), Rectangle, Circle, Arc
  Solidi:    Box, Cylinder, Sphere, ExtrudeCrv (curve chiuse -> solido)
  Modifica:  Move, Copy, Rotate, Scale, Mirror, Delete,
             Array (nx ny nz dx,dy,dz), ArrayLinear, ArrayPolar
  Curve 2D:  Offset (scrivi la distanza, poi clicca il lato), Trim (seleziona i
             tagli, Invio, poi clicca i pezzi da togliere), Extend (seleziona i
             bordi, Invio, poi clicca vicino all'estremità), Fillet (raggio, poi
             due linee), FilletCorners (raccorda tutti gli angoli di una polilinea)
  Unisci:    Join (curve che si toccano -> polycurve; mesh -> una mesh),
             Explode (polilinee/polycurve -> segmenti; box -> facce)
  Selezione: SelAll, SelNone
  Layer:     Layer <nome> (corrente), ChangeLayer <nome> (sposta la selezione)
             oppure clic sul nome nel pannello / tasto destro; nel pannello
             Layers: occhio = mostra/nascondi, lucchetto = blocca, quadratino
             colorato = colore del layer
  Colori:    pannello Properties (F3): layer dell'oggetto, colore "By Layer" o
             personalizzato; da riga di comando SetObjectColor rosso / 255,0,0 /
             #ff0000 / ByLayer, LayerColor <colore> [layer]
  File:      New [mm|cm|m], Open, Save, Save As
  Viste:     ZE (zoom estensioni vista attiva), ZEA (tutte), Top, Front, Right,
             Perspective · Help = elenco completo

Snap (barra di stato)
  End, Mid, Cen, Quad sugli oggetti; Grid Snap con passo regolabile; Ortho.

Note
  - Salvando un file aperto da Rhino, la prima volta Forma propone un nuovo nome
    (nome-forma.3dm): le superfici importate vengono salvate come mesh.
  - Booleane (BooleanUnion/Difference) e raccordi sugli spigoli dei solidi
    arriveranno con il kernel OpenCascade: nei menu sono visibili ma disattivati.
  - Offset/Trim/Extend lavorano su linee, polilinee, archi e cerchi nel loro
    piano (le curve importate da Rhino arrivano come polilinee).

forma-cli.exe: versione a riga di comando (info, render in PNG, script).
